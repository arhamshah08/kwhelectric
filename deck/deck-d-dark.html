The problem
One battery. Four tolls.
To dispatch a single customer's battery, a utility routes through an aggregator, an integrator, and the OEM's own cloud — each one taking a fee and adding delay. Then it repeats, in full, for the next customer. And the next.

Slide 4 · Solution
The solution
One gateway. Four jobs.
kWh Electric is an edge gateway that sits on-site and speaks every asset's native protocol. It connects the device, normalizes its data into one model, dispatches commands in real time, and verifies every event as it happens.
Connect
Speaks the asset's own protocol, on-site.
Normalize
Turns every dialect into one clean model.
Dispatch
Sends setpoints from any platform, live.
Verify
Logs the event, before, during, after.

The solution, underneath
Every dialect in. One trusted language out.
