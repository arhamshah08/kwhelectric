The problem

Today, the hive
is fragmented.

Every OEM locks its devices in a separate silo. Over 100 million DERs are deployed worldwide with no common dispatch layer beneath them.

80%

of DER fleets still lack dispatchability. Existing APIs are too expensive, and lack interoperability and security.

Each silo was built correctly. None of them was built to be read by anyone else.

just crossed.

DER growth has outrun the infrastructure built to carry it, and interconnection rules just made dispatchability mandatory.

The solution · agentic

An agent can plan a dispatch.
Nothing lets it act.

There is no interface between a model that reasons and hardware that must not be wrong.

No bounded interface

An API key to a battery is not a safety model. Access is not the same as authority.

No policy at the edge

If the link drops or the model errs, nothing on site stops the command from executing.

No verifiable record

An action nobody can audit is an action nobody will authorise. Utilities do not sign for a black box.

Agent proposes

MCP-native. The agent queries the hive and requests an action in the same language every asset already speaks.

Boundary
The cell disposes

Policy-as-code runs on the edge device. Every request is checked against that asset's safe operating envelope before anything moves.

The same lit cell that turns the wasp away bounds the agent. One security model, two threats, no extra engineering.

The agent can ask the hive for anything. The cell decides what is safe.

Model B — at the transformer
Loading and health

kVA vs rating · overload events and duration · oil and winding temperature · estimated loss-of-life · tap position

Power quality, LV side

Per-phase voltage · phase imbalance · reverse power flow duration · sags, swells, interruptions

Loss and efficiency

Energy through the transformer per interval · input vs downstream consumption for AT&C loss localisation · overloaded vs underutilised DTs

Reliability

Outage and restoration timestamps · interruption duration and frequency feeding SAIDI and SAIFI · last-gasp reporting through power-loss ride-through

Fewer transformer failures AT&C loss localisation SAIDI / SAIFI at fine grain Rooftop solar without LV overload Deferred transformer replacement
