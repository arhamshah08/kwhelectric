Notes — how effects like the Artisan reference get made

What's pure CSS (I can build this directly, no external tool needed):

• The dark radial "glow" behind the headline (theme 4) — radial-gradient() layered on a flat dark background.
• The dotted grid texture (theme 5) — a repeating radial-gradient dot pattern used as a background-image tile.
• Soft grain/noise overlay — an inline SVG <feTurbulence> filter at low opacity, no image file needed.
• The glassy blurred card in theme 4 — backdrop-filter: blur() + a translucent panel background.

What needs an external tool:

• The 3-person hero render in the Artisan cover — that's AI image generation (Midjourney / ChatGPT / Nano Banana), same pipeline you're already using for the deck PNGs, not something CSS can produce.
• If you want a hand-tuned mesh/blob gradient background as a raster asset instead of live CSS: Haikei.app (free blob/gradient/mesh generator, exports SVG or PNG) or meshgradient.com are the fastest no-design-skill options. Figma's "Mesh Gradient" community plugin is the equivalent if you're already in Figma.

On the purple: Artisan's violet/purple accent conflicts with kWh's locked one-accent-color rule (green only, no purple) from your design-system memory. Themes 3–5 above keep that rule. If you want to see a purple variant anyway to compare, say so and I'll add it as an explicit sixth option rather than silently changing the rule.
